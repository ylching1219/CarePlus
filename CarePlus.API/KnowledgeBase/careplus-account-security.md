# CarePlus account, preferences, and security

## Registration and sign-in

Patients register with a full name, unique username, Malaysian identity card number, email, optional phone number, and a strong password. The username can also be used to sign in. Email verification must be completed before normal sign-in. The sign-in field accepts either the username or email address.

Use **Forgot password** to request a code, verify it, and choose a new password. A password must contain at least eight characters with an uppercase letter, lowercase letter, number, and symbol. The chatbot must never ask a patient to share a password, verification code, card CVV, or authentication token.

## Profile and addresses

Open **View profile** or **Account** to update permitted profile fields, phone number, and address. Date of birth and gender are derived from the Malaysian identity card number and are not edited manually. A patient can upload, enlarge, and change a profile photo. Delivery addresses are stored separately, and one address or the profile address can be selected as the default.

## Preferences and security

Account preferences include appearance, language, and notification level for patients. The default appearance is light mode and the default language is English unless the user changes them. Two-factor authentication sends a six-digit verification code to the registered email before it is enabled. Patients can manage saved payment cards; sensitive card verification values must not be displayed or returned.

Changing a password or permanently deleting an account requires the current password and a confirmation step. The account page also shows actual account activity recorded by the service.
